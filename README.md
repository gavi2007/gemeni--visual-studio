# Gemini AI - VS Code Extension

An AI-powered extension for Visual Studio Code that integrates Google's Gemini API directly into your editor workflow to streamline coding, debugging, and code generation.

---

## ⚡ Key Features

* **In-Editor AI Assistance:** Get code explanations, refactoring suggestions, and bug fixes directly within VS Code.
* **Smart Code Generation:** Generate boilerplate code and functions using custom prompts.
* **Powered by Gemini API:** Leverages Google's latest Gemini models for high-speed, accurate coding support.

---

## 🛠️ Tech Stack & Prerequisites

* **Language:** TypeScript / JavaScript
* **Environment:** Node.js (v18.0+)
* **API Key:** Google Gemini API Key (via [Google AI Studio](https://aistudio.google.com/))
* **Editor:** Visual Studio Code (v1.80+)
